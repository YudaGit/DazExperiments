Typing Race Scheduler

Main menu

Enter participant information, choose a word bank, then proceed when you are ready.

The length-range word bank (word_bank.json) is active by default.

Instructions

  • Each task window moves from right to left; finish the highlighted word before it hits the deadline.
  • Type the first letter to lock into a task, then complete the rest of the word.
  • Press ESC to release a task when you need to switch—otherwise the trial continues automatically.

Practice trials

Practice a single trial to get familiar. When it finishes the trial-action button below will reappear.

Thank you for taking part in this study on visual memory. In this experiment, you viewed brief displays of colored patches or colored orientation bars and then reported a target item using a wheel. The aim is to understand how people encode and retrieve visual features such as color and orientation, and how performance changes with exposure durations, set size, redundancy, and cues. These tasks allow us to estimate the precision of visual working memory representations and the strategies people use when encoding and retrieving visual information.

Your data will help us test computational models of visual working memory, specifically the encoding and decoding decisions of memorised features and stimuli context. These models can help us to gain insights into when and how redundant visual information benefit memory performance.

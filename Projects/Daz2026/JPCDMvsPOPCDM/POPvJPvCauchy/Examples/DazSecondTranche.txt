Wrapper/fitting scripts in POPvJPvCauchy:
- [pgpop1.m](pgpop1.m): POP likelihood wrapper for Paul small-range data, M = [1, 2, 3, 4], likely pga4.
- [pgpop1a.m](pgpop1a.m): POP likelihood wrapper for Paul large-range data, M = [1, 2, 4, 6], likely pga6.
- [vwmjp61.m](vwmjp61.m): JP likelihood wrapper for small-range data, M = [1, 2, 3, 4].
- [vwmjp61a.m](vwmjp61a.m): JP likelihood wrapper for large-range data, M = [1, 2, 4, 6].
- [setopt.m](setopt.m): old-style fminsearch option helper, more of a command reminder than a full fitting script.

New JP calling conventions:

  [ll,ll2, aic, qbic,Pred] =  vwmjp61(Pvar, Pfix, Sel, Data, trace)
      P = [nrm1:nrm4 k1:k4, eta1..eta4, Psi1..Psi4,   B,     A,   alpha, a, Ter1:Ter4 st, delta, beta]  
          1:4     5:8      9:12        13:16    17:20  21:24   25   26   27:30   31    32    33

now passes back 2 x LL as well as LL. LL has a quadratic penalty for bound violation which we don't want in the model selection statistics, only in the minimization. ll2 is 2 x LL and the AIC and BIC are calculated without the penalty. 

<vwm61> is for small range experiment M = [1,2,3,4]; <vwm61a> is for large range experiment M = [1,2,4,6]. Pop code model also returns ll2.

mvwm23(pga4, Pred, [2.5, 2.5]) plots marginals; <mvwm23a> does the same for the large range (just the labels are different). The optional last argument sets y-axis scaling for accuracy and x-axis scaling for RT.

 qvwm23(@pgpop1a, P(Sel==1), P(Sel==0), Sel, pga6, [.5,2.0])

does Q x Q plots. Passes in the function, the parameters used in the fit, the data, and optional yaxis-scaling.
